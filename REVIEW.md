views, маршруты, администрирование, миграции, оба набора тестов, workflow и авторские страницы.

общая лента с кешированием, лента подписок, сообщества, пагинация и права редактирования.

Python 3.11 и совместимые зависимости установлены в отдельной `.venv`.

Устранена привязка CI к чужому репозиторию/SSH-key: workflow запускает тесты текущего дерева.
Удалены устаревшая дополнительная загрузка Bootstrap и закомментированная заготовка скрипта.

## Запуск

Полная инструкция — README.md. После подготовки `.env`:

```powershell
.\.venv\Scripts\python.exe yatube\manage.py migrate
.\.venv\Scripts\python.exe yatube\manage.py loaddata travel_communities
.\.venv\Scripts\python.exe yatube\manage.py createsuperuser
.\.venv\Scripts\python.exe yatube\manage.py runserver 127.0.0.1:8003
```

## Ограничения

Письма восстановления пароля сохраняются в `yatube/sent_emails/`; внешний SMTP не настроен.
Проверка через HTTP не включала визуальный браузерный прогон; выпадающая мобильная
навигация использует Bootstrap JS с jsDelivr.
Отдельной лицензии нет; новые условия дальнейшего распространения не назначались.

Django 4.2.30 выбран как совместимая ступень для Python 3.11. Ветка 4.2 уже завершила
период поддержки; для публичного размещения требуется отдельное обновление до поддерживаемой LTS.
Сохранённый выход через GET даёт deprecation warning для будущего Django 5;
переход на POST должен сопровождаться обновлением интерфейса и проверок.

 Вариант будущего сообщения:
